# 💼 Portfólio Pessoal

Este projeto foi desenvolvido com o objetivo de apresentar meus projetos, habilidades e experiências como desenvolvedor full stack.

O portfólio reúne informações sobre minha trajetória na área de tecnologia, tecnologias que utilizo atualmente e alguns dos projetos que desenvolvi durante meus estudos e experiências práticas.

---

## 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido utilizando:

- Vue.js
- JavaScript
- HTML5
- CSS3
- Node.js
- PostgreSQL

---

## 🎯 Objetivo do projeto

O principal objetivo deste portfólio é criar um espaço moderno e responsivo para:

- Apresentar meus projetos
- Demonstrar minhas habilidades técnicas
- Compartilhar minha evolução como desenvolvedor
- Centralizar informações profissionais e formas de contato

---

## 📱 Funcionalidades

- Página inicial de apresentação
- Sessão de projetos
- Tecnologias e habilidades
- Informações de contato
- Layout responsivo
- Navegação dinâmica

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, estou aprimorando conhecimentos em:

- Desenvolvimento front-end com Vue.js
- Consumo de APIs e requisições HTTP
- Componentização
- Responsividade
- Estruturação de aplicações web
- Integração entre front-end e back-end
